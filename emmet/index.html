# Concepto Abreviatura Resultado
01 Child
Crea elementos hijos (anidación)		 ul>li>a <ul><li><a href=""></a></li></ul>
02 Sibling
Crea elementos hermanos		 section+header+nav <section></section><header></header><nav></nav>
03 Multiplication
Repite elementos N veces		 ul>li*3 <ul><li></li><li></li><li></li></ul>
04 Class
Crea un atributo class		 div.contenedor <div class="contenedor"></div>
05 Multiple Classes
Varias clases en un elemento		 div.clase1.clase2.clase3 <div class="clase1 clase2 clase3"></div>
06 ID
Crea un atributo id		 nav#menu <nav id="menu"></nav>
07 Text
Inserta contenido de texto		 div{Hola Mundo} <div>Hola Mundo</div>
08 Custom Attribute
Atributos personalizados		 a[href="https://google.com" target="_blank"] <a href="https://google.com" target="_blank"></a>
09 Item Numbering
Numeración consecutiva		 ul>li.item$*3 <ul><li class="item1"></li><li class="item2"></li><li class="item3"></li></ul>
10 Reverse Numbering
Numeración inversa		 ul>li.item$@-*3 <ul><li class="item3"></li><li class="item2"></li><li class="item1"></li></ul>
11 Base Numbering
Numeración desde base		 ul>li.item$@3*4 <ul><li class="item3"></li><li class="item4"></li><li class="item5"></li><li class="item6"></li></ul>
12 Climb Up
Sube un nivel en el árbol		 section>article>div^p <section><article><div></div></article><p></p></section>
13 Grouping
Agrupa elementos		 (header>nav)+(section>article) <header><nav></nav></header><section><article></article></section>
14 Lorem
Texto placeholder		 lorem20 Lorem ipsum dolor sit amet consectetur adipisicing elit. Quisquam, quos illo.
15 HTML Document
Estructura HTML5		 html:5 <!DOCTYPE html><html lang="en"><head><meta charset="UTF-8"><title>Document</title></head><body></body></html>
16 Meta Tags
Meta viewport		 meta:vp <meta name="viewport" content="width=device-width, initial-scale=1.0">

Ejercicio Challenge

Genera un navbar completo de Bootstrap usando una sola línea de Emmet:

header#header>nav.navbar.navbar-inverse>div.container>(div.navbar-header>(button[type="button"].navbar-toggle>span.sr-only{Toggle navigation}+span.icon-bar*3)+a.navbar-brand[href="index.php"]>img[src="imgs/logo.png" alt=""])+div.collapse>ul.nav.navbar-nav>(li>a.link[href="index.html"]{Inicio})+(li.active.link>a[href="login.html"]{Ingresar})+(li>a.link[href="registro.html"]{Registrarse})+(li>a.link[href="contacto.html"]{Contacto})
