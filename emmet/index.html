EMMET

Plugin for faster HTML and CSS coding.

Child

creates child elements ( nesting )

example

ul>li>a

Result

<ul> <li> <a href=""></a> </li> </ul>

Sibling

creates sibling elements

example

section+header+nav

Result

<section></section> <header></header> <nav></nav>

Multiplication

repeats elements multiple times

example

ul>li*3

Result

<ul> <li></li> <li></li> <li></li> </ul>

Class

creates a class attribute

example

div.contenedor

Result

<div class="contenedor"></div>

Classes

creates multiple class attributes

example

div.clase1.clase2.clase3

Result

<div class="clase1 clase2 clase3"></div>

Id

creates an ID attribute

example

nav#menu

Result

<nav id="menu"></nav>

Text

inserts text content

example

div{Hola Mundo}

Result

<div>Hola Mundo</div>

Custom Attribute

creates custom attributes

example

a[href="https://www.google.com" target="_blank"]

Result

<a href="https://www.google.com" target="_blank"></a>

Item Numbering

adds consecutive numbers

example

ul>li.item$*3

Result

<ul> <li class="item1"></li> <li class="item2"></li> <li class="item3"></li> </ul>

Reverse Numbering

inverts numbering order

example

ul>li.item$@-*3

Result

<ul> <li class="item3"></li> <li class="item2"></li> <li class="item1"></li> </ul>

Base Numbering

defines a base number for sequences

example

ul>li.item$@3*4

Result

<ul> <li class="item3"></li> <li class="item4"></li> <li class="item5"></li> <li class="item6"></li> </ul>

Climb Up

moves up one level

example

section>article>div^p

Result

<section> <article> <div></div> </article> <p></p> </section>

Grouping

groups elements together

example

(header>nav)+(section>article)

Result

<header> <nav></nav> </header> <section> <article></article> </section>

Lorem

generates placeholder text

example

lorem20

Result

Lorem ipsum dolor sit amet consectetur adipisicing elit. Quisquam, quos illo. Voluptates, quae. Lorem ipsum dolor sit.

HTML Documents

creates various HTML document types

example

html:5

Result

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Document</title> </head> <body> </body> </html>

Meta Tags

generates meta tags

example

meta:vp

Result

<meta name="viewport" content="width=device-width, initial-scale=1.0">
